# V01 분석과 새로운 V02 구조 차이

이번에는 두 시제품을 같은 파라미터와 기구로 비교한다. A는 PSA 슬랩 직접 수납, B는 기존 알루미늄 보호케이스 수납이다. V01과 이전 아이보리 구매 팝업 개념 V02는 보존했다.

|항목|V01|이전 아이보리 V02|이번 V02 A/B|
|---|---|---|---|
|수납 대상|판매자 외형86×142×11 케이스|같은 케이스|A 슬랩81×136×6 가정 / B 케이스86×142×11 미실측 참고|
|교체|M3 게이트2개, 도구 필요|M3 게이트2개|고정핀 없는 자석 게이트, 들어올리고 위로 분리|
|이탈 방지|앞립/뒷판/나사|앞립/뒤림/나사|앞립/뒤림/자석2쌍/+Y 기계적 끝벽2곳|
|접이 기구|단일32mm 링크, 상부핀/하부마찰|상용 원형 팝업 외형만|실제 링크2개/4회전축의 평행링크,0/90도 인덱스핀2개|
|폰 부착|자석모듈 미선정|자석모듈 미선정|케이스 접착식 평면 베이스; 하부 축2개로 본체 분리|
|색상|청회색 기구색|아이보리|매트 블랙 / 블랙×실버, 부품별 출력|
|미확정|기존케이스/부착부/마찰/실강도|상용 팝업과자석체결전체|수납물실측, 자석·접착 선정,표준핀 스택,출력/실강도|

중요한 구조적 선택:

- 외관만 바꾸지 않고 수납 구조와 기능 기구를 실제 모델링했다. 상용 원형 팝업은 대안으로 비교하되 공급사 기구도/하중 데이터가 없어 이번 제작 기구로 가정하지 않았다.
- 사용자 후속 요청으로 게이트의 카드 교체용 고정핀을 자석으로 바꿨다. 링크의 회전축핀과 각도핀은 별도 내부 기구로 남아 있다. 자석이 역회전/각도 고정을 대신하지 않는다.
- 두 자석쌍은 게이트가 바깥쪽으로 들리는 것을 억제한다. 닫힌 게이트 발은 끝벽에 걸려 단순 위쪽 탈출을 막는다. 들린 상태에서는 이 걸림이 해제되므로 자석의 실제 박리/충격 유지력이 반드시 필요하다.
- 폰 연결은 접착식이다. 접착제는 폰 케이스와 출력 베이스 사이에만 적용하고 기존 카드/슬랩/알루미늄 보호케이스에는 적용하지 않는다. 본체를 떼어도 접착 베이스는 폰 케이스에 남는다.
- 핀·링크를 실재하게 넣은 현재 기구는 상용 주름형 그립보다 두껍다. 단순히24/40mm 같은 콘셉트 치수를 맞추기 위해 하중부를 제거하거나 미검증 TPU 주름을 완성품이라고 만들지 않았다.
- 스냅핏보다 자석과 금속핀을 택해 출력 탄성팔 반복피로를 줄이는 방향이지만, 자석/핀/층간 파손/반복/접착을 실물 검증한 것은 아니다.

PSA 공식 규격 확인은 네트워크403으로 실패했다. 63×88mm는 내부 카드의 표시 크기에만 사용하고 슬랩 외형으로 사용하지 않았다. 모든 미측정 입력은 CSV와 JSON에 기록했다. 실제 시제품 제작 확정은 수납물·폰·구매 자석·핀·접착제 실측 및 시험 후에 해야 한다.
